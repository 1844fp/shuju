# Implementation notes

## Deviations
- 现worker不支持协作停止，新增包装子进程按--once调用，保留原实现；仅tick间协作退出，tick超时会核验身份后终止。
## Discovered edge cases
- 父进程崩溃可能留下子进程；子进程检查父身份，重启还需核对旧子进程防止重复调度。
- 心跳证明循环存活不证明数据库tick完成；配置组织/库对应由受信管理员显式指定。
## Questions for review
- 无需外部配置或真实日程，本轮仅模拟库验证。

## 实施与复验补充
- Windows状态文件即使原子替换也可与读句柄短暂冲突，已在读/替换增加40次×25ms有界重试；唯一临时文件finally清理。
- 同一个简报日多次worker执行通过原有唯一键保持一份；监督器是至少一次调度，不对外部副作用作恰好一次保证。

总结：2项保守实现选择（包装once、状态共享重试）。
最可能后续调整：长期日志轮转和生产常驻方式。
发现边界：Windows共享、父崩溃孤儿、tick阻塞与停止超时、配置库组织对应。
实际验证：4项真实进程测试全部通过，11.754秒。
