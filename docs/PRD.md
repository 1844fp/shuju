# 产品需求基线

## 用户与场景
财务人员导入凭证与费用数据；经营管理者查看收入、成本、经营利润和趋势；分析人员通过受控问答获取带来源的分析。

## 分期
P0 初始化：目录、规范、架构、API 与数据模型草案、角色任务和环境模板。
P1 可运行闭环：模拟凭证、CSV/Excel 上传预览与确认、清洗隔离、分层数仓、统一指标、财务驾驶舱。
P2 智能增强：LangGraph Supervisor、受控查询、异常检测、可追溯报告、MCP 与带引用知识检索。
P3 治理部署：认证、RBAC、组织隔离、审计、血缘、Docker 和 CI。

## 首期验收
有效凭证借贷平衡；重复导入不重复计数；错误行可按文件行号追踪；驾驶舱与 SQL 汇总一致；零收入比率为 null；跨币种不混算；问答无法执行写操作。

## 边界
初版不自动入账、支付、预测或宣称符合全部会计准则。完整利润表、现金流分类和多租户上线分别验收。

## 首期模板定稿（2026-11-04）
八列固定为 posting_date,voucher_no,line_no,account_code,department_code,currency,debit,credit。CSV使用UTF-8，可带BOM；XLSX读取活动表，首行为列名，日期建议使用YYYY-MM-DD文本。文件上限10MB、10000条数据。

posting_date为ISO日期；voucher_no必填且最多100字符；line_no为正整数；account_code为字符串，当前仅1002/6001/6401/6602；department_code列必须存在，值可空；currency为三位大写代码（当前不验证币种目录）。debit/credit非负、最多两位小数、上限999999999999.99，空值当前按零，每行恰好一方大于零。冲销使用相反借贷方向，不接收负数。

字段映射方向为标准名到文件列名，八个键必须齐全。按日期、凭证号、币种整组校验隔离。业务键当前为来源系统、年度、凭证号、行号，不含日期和币种。相同文件哈希返回原批次，修改映射或来源系统不能重导同一文件。committed允许部分凭证隔离，必须同时展示accepted_rows/rejected_rows。下载模板含模拟记录，上传标记uploaded不代表真实性认证。

验收涵盖反向冲销、两种重复导入、未知科目、整凭证隔离、空部门、零收入、分币种与来源一致性；跨组织验收属于认证上线门槛。

剩余验收：真实PostgreSQL适配及dbt对账；生产身份配置、HTTPS和跨组织并发越权；真实模型及外部MCP握手；任务队列的重试、恢复与取消；Docker实跑与远端CI；银行对账、现金流、预测、完整利润表及PDF/Excel。预算只核对费用类实际额，账龄使用当前未结余额，不能承诺历史余额复原。
