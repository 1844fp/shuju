# 企业级剩余功能与落地顺序

本项目已具备前后端、财务接入清洗、隔离与幂等、组织身份权限、指标报表、PG数仓、受控模型知识分析和本机运行保障。它尚不是完成生产签收的企业数据平台。本清单优先于历史文档中笼统的“完整完成”表述。

## 本轮已补齐

中台月度接收锁、基于固定快照的可选双人复核、企业自定义科目到报表的显式映射、ERP原始文件与隔离记录的PG发布、本地控制审计校验。使用和实际证据见 `ENTERPRISE_CONTROLS_ACCEPTANCE.md`。

## 上线前优先

1. **企业身份与细粒度权限**：现有users会话、角色和组织隔离已有测试；还缺OIDC/SAML单点登录、MFA/企业身份生命周期、部门/账套/敏感字段授权、权限变更复核和正式环境越权签收。需要企业IdP、组织权限矩阵、正式域名证书；不得继续使用演示身份上线。
2. **真实ERP持续采集**：已有文件与服务器登记的只读DB/API，字段预设覆盖常见软件；还缺客户版本认证、增量游标/CDC、持久调度、退避重试、源端快照与断点恢复、删除/更正语义。需要只读测试实例、字段字典、账套与期间规则。Python驱动就绪不代表MySQL/SQL Server或厂商实例已联通。
3. **容器与灾备签收**：已有构建CI、本机备份恢复、PG恢复、监控与事件重试；还缺本机Compose全服务/worker/持久卷联调、开机自启、计划备份、保留期、加密异地副本、真实通知渠道、整机/异机恢复与PITR演练。需要RPO/RTO、存储目的地和值守渠道。Docker引擎启动不等于这组验收通过。
4. **容量与安全验收**：还缺目标并发/数据规模的长期压测、容量预算、HA/故障切换、密钥轮换与审计外部存证。现有小样本响应检查不外推企业SLA。需要用户量、账套数、每日凭证量、峰值并发及保留年限。

## 业务与治理扩展

- **完整财务口径**：现有固定公式和简化报表；还缺企业核准的完整报表项目、会计制度差异、辅助核算、合并抵销/多主体、汇兑折算、重分类与追溯调整。不同币种继续分开，未核准范围不宣称审计口径。
- **主数据与数据契约**：现有科目核准和不可静默重分类；还缺客户/供应商/部门统一主数据、层级与有效期/SCD2、数据契约版本兼容、跨来源业务键治理。
- **质量运营**：现有凭证校验隔离、人工清洗和来源追溯；还缺业务可配置质量规则版本审批、阈值告警、质量工单、负责人分派及源/仓/报表自动勾稽闭环。
- **合规生命周期**：还缺字段脱敏、授权导出复核、保留/删除策略、法定留存与独立不可篡改审计；具体要求由企业制度与适用规则确定。
- **知识与模型运营**：已有公开资料评测、受控工具和本地语义；还缺企业私有知识权限分层、标注集持续评测、漂移回归、版本灰度、调用成本与供应商故障切换。公开固定样本通过不代表企业真实问答准确率。
- **交付治理**：目前版本分支保留源码；尚缺保护分支、正式Release/tag、签名制品、环境晋级与自动回滚、数据库前后兼容升级演练。

## 执行方式

下一阶段先做持续采集与质量工单的内部实现，并用明确模拟数据验收；真实ERP与企业身份、目标部署和灾备所需配置到位后，再进行环境联调。每个阶段都保留原始输入、固定契约、精确金额、组织权限与可复现证据，不把接口存在写成已完成生产签收。本轮没有向任何企业ERP入账、付款或调整。
